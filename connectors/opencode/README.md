# opencode

The OpenCode connector: Zen (`opencode-zen`) and Go (`opencode-go-subscription`, `opencode-go-messages`, `opencode-go-glm`) by API key, the `opencode` login module (a login borrowed from the OpenCode CLI) and the `opencode-go` usage probe.

Layout: `routes/`, `profiles/` (models only this vendor serves), `components/` (module sources); see `connectors/README.md` and ADR-0217. Filled by units 2 and 3 of #924.
