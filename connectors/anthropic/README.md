# anthropic

The Anthropic connector: the Messages API by API key (`anthropic`) and through a Claude Code login (`anthropic-subscription`), the `claude-code-oauth` login module and the `claude` usage probe.

Layout: `routes/`, `profiles/` (models only this vendor serves), `components/` (module sources); see `connectors/README.md` and ADR-0217. Filled by units 2 and 3 of #924.
