- `{{tool:grep}}` searches file contents and lists files; use it instead of shell grep, rg or find. `mode: "content"` (the default) shows matching lines grouped by file, `mode: "files"` lists matching paths (with an empty `pattern` and a `glob` it lists files by glob), `mode: "count"` counts matching lines per file. Set `literal: true` for exact text, scope with `path` and `glob` in large trees, and continue a cut result from the `offset` its footer names instead of repeating the search.
