# Security policy

## Supported versions

phaseone is pre-release and has no version numbers yet. Security fixes go to `main` and ship in the next release (`main-<sha>`); only the latest release is supported. Update with `p1-update`.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's private vulnerability reporting: the **Report a vulnerability** button on the repository's [Security tab](https://github.com/5omeOtherGuy/phaseone/security/advisories/new).

Include what you found, how to reproduce it, and the release (`p1 --version`) or commit you tested. Leave out real credentials or tokens; describe them instead.

You get an acknowledgement within 7 days. The fix is prepared in a private security advisory, released, and then the advisory is published with credit to you, unless you ask not to be named.
