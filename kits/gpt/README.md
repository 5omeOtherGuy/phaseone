# gpt

The GPT kit (family `gpt`): the Codex tool pair `shell` + `apply_patch`, the GPT prompt profile
and the compaction preferences of today's `gpt` environment. That environment's `[context]`
numbers describe the Codex subscription's served window, not the public API's; they belong to
the Codex route's model binding, not here.

Layout: `kit.toml`, optional `<profile-id>.toml` overrides, `summarize.md`; see `kits/README.md`
and ADR-0217. Filled by unit 4 of #924.
