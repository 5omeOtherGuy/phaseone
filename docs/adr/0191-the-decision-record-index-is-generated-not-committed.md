# ADR-0191: The decision-record index is generated, not committed

## Context

ADR-0030 kept a table of every record between markers in `docs/adr/README.md`, regenerated by
`scripts/adr.py index` and compared by `scripts/adr.py check`. Every pull request with a record
added a row to that table, so any two such pull requests open at the same time conflicted there.
Resolving the conflict means merging `main` into the branch, and the new head runs the whole gate
again. On 2026-10-11 the dispatcher asked whether work had a bottleneck; the answer named this
table as the conflict nearly every pull request hits. The owner ordered: "Build the index file,
fast track it onto main."

## Decision

The index is no longer committed. `scripts/adr.py index` prints the Markdown table (number, linked
title, status, date, deciders) and `scripts/adr.py list` prints one line per record; neither writes
a file. `scripts/adr.py check` validates the records and no longer compares a README block; it
reports a README that still carries the old index block, which only a merge that kept a stale
side can bring back. This narrows ADR-0030's index rule; the rest of ADR-0030 stands.

## Consequences

Two pull requests with records no longer conflict unless they touch the same file. A reader on
GitHub sees the records through the directory listing, whose file names are the titles, or runs
`scripts/adr.py index`; the at-a-glance status column is no longer on the page. Pull requests open
when this lands still carry a row in the old table; on merging `main` they take main's
`docs/adr/README.md`, as `AGENTS.md` says.

## Alternatives considered

- A git merge driver for the table: GitHub's server-side merge, which decides whether a pull
  request is mergeable and performs auto-merge, does not run custom drivers.
- Regenerating the table on `main` after each merge: `main` takes changes only through a pull
  request with a green gate, so a bot commit would itself be a pull request and a gate run.
- One index file per record: GitHub does not concatenate files, so it gives no single page either.

## Evidence

On 2026-10-11 PR #807 conflicted twice, after #805 and after #809 merged, in
`docs/adr/README.md` and `docs/design/seams.md`; each resolution re-ran the full gate. Green gate
runs of code pull requests took 21 to 41 minutes (16 runs measured with
`gh run list --workflow ci.yml`). Check: `python3 scripts/test_adr.py` and
`python3 scripts/adr.py check`.
